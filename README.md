# Welcome to the Learning Hub

Welcome! This repository serves as the central starting point for our coding curriculum. It is designed to take you from the very fundamentals of programming all the way to building modern, interactive web applications. 

Whether you are starting fresh or looking to sharpen your skills, the modules here provide a structured path with hands-on exercises and projects.

## Curriculum Tracks

Currently, the learning hub consists of two main tracks. We recommend completing the JavaScript Fundamentals track before diving into React.

### 🟨 Track 1: JavaScript Fundamentals
The core building blocks of the web. This track covers the language syntax, how to organize data, and how to make web pages interactive.

- [Stage 1: Building Blocks](./js/1_building_blocks.md) - Variables, Data Types, Operators.
- [Stage 2: Decision Making](./js/2_decision_making.md) - Conditionals and Logic.
- [Stage 3: Functions](./js/3_functions.md) - Reusable code blocks.
- [Stage 4: Data Organization](./js/4_data_organization.md) - Arrays and Objects.
- [Stage 5: The DOM](./js/5_dom.md) - Interacting with the webpage.
- [Stage 6: Async JavaScript](./js/6_async.md) - Promises, Fetch, and handling time.
- [Cheat Sheet](./js/cheatsheet.md) - Quick reference for JS syntax.

### ⚛️ Track 2: React Mastery
A modern approach to building user interfaces. Once you are comfortable with JavaScript, this track will teach you how to build scalable, component-driven web applications.

- [Stage 1: Components](./react/1_components.md) - The Component Mental Model and JSX.
- [Stage 2: Props](./react/2_props.md) - Passing data between components.
- [Stage 3: State](./react/3_state.md) - Interactive components and state management.
- [Stage 4: Side Effects](./react/4_side_effects.md) - `useEffect` and data fetching.
- [Stage 5: Context](./react/5_context.md) - Global state management.
- [Stage 6: Navigation](./react/6_navigation.md) - Routing in React applications.
- [Final Project](./react/final_project.md) - Bringing it all together.

## How to Use This Curriculum

1. **Follow the Order:** The stages are numbered sequentially. Each stage builds upon the concepts learned in the previous ones.
2. **Do the Micro-Exercises:** You will find "Micro-Exercises" scattered throughout the lessons. Do not skip these! They are designed to cement your understanding before moving on.
3. **Build the Projects:** At the end of each stage, there is a mini-project. This is where the real learning happens.
4. **Experiment:** The code examples provided are just the starting point. Play around with them, break them, and figure out how to fix them.

## Future Updates

This repository is a living document. As new technologies emerge and best practices evolve, new courses and modules will be added. Stay tuned for future tracks!
